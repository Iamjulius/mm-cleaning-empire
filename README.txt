PUBLISH WITH GITHUB PAGES
1. Sign in to GitHub and create a repository named mm-cleaning-empire.
2. Upload index.html into the repository's root folder.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select branch "main" and folder "/ (root)", then Save.
6. Wait a few minutes. Your website URL will look like:
   https://YOUR-GITHUB-USERNAME.github.io/mm-cleaning-empire/
